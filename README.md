# AI оператор внутренней IT поддержки ВекторЛаб

Учебный проект демонстрирует настоящий RAG и автоматический гибридный поиск по русскоязычной базе знаний вымышленной организации «ВекторЛаб». Итоговое приложение должно отвечать только на основании найденных фрагментов, показывать источники и открывать пользователю диагностику обоих поисковых каналов.

## Требования PRO задания

В план реализации входят векторный поиск по embeddings, лексический поиск BM25, объединение результатов через Reciprocal Rank Fusion, удаление дублей и передача выбранных Top-K фрагментов языковой модели. Если подтверждённой информации в базе нет, приложение должно прямо сообщать об этом.

Интерфейс будет показывать один итоговый ответ, использованные документы и разделы, результаты Vector Search, результаты BM25 и окончательный контекст после RRF. Документы базы можно будет добавлять, заменять и удалять с последующей повторной индексацией без изменения программного кода.

## Предполагаемая архитектура

1. Индексатор читает Markdown-документы, извлекает метаданные и делит текст по смысловым заголовкам.
2. Для чанков создаются embeddings и локальный индекс FAISS.
3. Из тех же чанков строится корпус BM25 с отдельной токенизацией русского текста и сохранением технических кодов.
4. При каждом вопросе оба канала возвращают собственные ранжированные списки.
5. RRF объединяет списки по стабильному идентификатору чанка, после чего выбирается итоговый Top-K.
6. Только итоговые фрагменты передаются LLM для формирования ответа с указанием источников.
7. FastAPI обслуживает API и статический русскоязычный интерфейс.

## Структура проекта

```text
app/                         будущий backend и поисковый контур
  rag/                       индексирование, поиск и объединение результатов
  static/                    будущий HTML, CSS и JavaScript
knowledge_base/documents/    исходные документы базы знаний
scripts/                     служебные команды, включая повторную индексацию
storage/                     генерируемые локальные индексы и metadata
tests/                       контрольные вопросы и автоматические тесты
```

Исходные DOCX-файлы в корне содержат формулировки домашнего задания и не входят в индексируемую базу знаний.

## Текущий статус

Завершён этап 1: создан Git-репозиторий, подготовлен каркас каталогов и написаны 12 русскоязычных документов базы знаний. В документах согласованы правила, исключения, технические коды и контролируемые пересечения для будущих тестов поиска.

Программные компоненты RAG, embeddings, FAISS, BM25, RRF, FastAPI и веб-интерфейс пока не реализованы. Зависимости перечислены в `requirements.txt`, но на этом этапе не устанавливались.
