# Установка и обновление программ

## Базовый порядок

Программы на корпоративные устройства устанавливаются из каталога `VL Software Center`. Доступные там пакеты уже проверены на совместимость и лицензионные условия. Если нужной программы в каталоге нет, пользователь создаёт запрос Service Desk с названием, назначением, поставщиком и требуемым сроком.

Скачивание установщиков из поисковой выдачи, файловых обменников или писем запрещено. Наличие бесплатной версии программы не означает автоматического разрешения на её использование в организации.

## Административные права

Постоянные локальные административные права пользователям не выдаются. Для утверждённой установки специалист IT запускает пакет с отдельной служебной учётной записью. Пользователь не должен сообщать свой пароль или просить коллегу с расширенными правами выполнить установку.

Для тестовой лаборатории возможно временное повышение прав максимум на четыре часа. Оно предоставляется только на зарегистрированное тестовое устройство, после одобрения владельца продукта и IT. Временное повышение не разрешает отключать антивирус, шифрование диска или журналы безопасности.

## Запрос нового программного обеспечения

В заявке указываются:

- точное название и версия;
- ссылка на официальный сайт поставщика;
- рабочая задача, которую решает программа;
- количество пользователей;
- необходимость платной лицензии;
- формат данных, которые будет обрабатывать программа.

Срок обычной проверки — до пяти рабочих дней. Срочность проекта сама по себе не отменяет проверку безопасности и лицензирования. Если существует утверждённый аналог, IT может предложить его вместо запрошенного продукта.

## Обновления

Критические обновления безопасности устанавливаются автоматически в объявленное окно обслуживания. Пользователь может отложить перезагрузку не более двух раз. Перед обновлением нужно сохранить работу и подключить ноутбук к питанию.

Orion ERP обновляется отдельно по регламенту владельца системы. Устанавливать локальный клиент Orion из старого дистрибутива или менять его файлы вручную нельзя; диагностика ошибок выполняется по `VL-IT-009`.

## Исключения и запрещённые действия

Портативная программа без установщика всё равно считается программным обеспечением и требует одобрения. Расширения браузера также входят в этот порядок, если они читают содержимое страниц или передают данные внешнему сервису.

Драйверы принтеров, VPN-клиент и средства шифрования устанавливаются только централизованно. Инструкция из интернета, предлагающая отключить защиту или запустить неизвестную команду с правами администратора, не является допустимым способом решения проблемы.

Если отсутствие программы полностью блокирует работу одного сотрудника, запрос остаётся запросом на обслуживание, а не инцидентом P1. Приоритет и тип обращения определяются по `VL-IT-012`.
