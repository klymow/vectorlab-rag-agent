# Сетевые папки и OneDrive

## Назначение хранилищ

OneDrive используется для личных рабочих файлов сотрудника и совместной работы над документами. Сетевые папки предназначены для материалов подразделений, к которым применяются общие права доступа. Хранить единственный экземпляр важного документа на рабочем столе или в локальной папке `Загрузки` нельзя.

При работе вне офиса доступ к сетевым папкам появляется только после подключения VPN. OneDrive может синхронизироваться через интернет без VPN, но пользователь всё равно обязан работать с корпоративного управляемого устройства.

## Ошибка FS-403

Код `FS-403` означает отказ в доступе к сетевой папке: у учётной записи нет требуемого разрешения либо срок временного доступа закончился. Код не означает, что файл удалён, и перезагрузка компьютера обычно не решает проблему.

Перед обращением:

1. Уточните полный путь к папке и название нужного раздела.
2. При удалённой работе убедитесь, что VPN подключён.
3. Проверьте, открывается ли другая папка подразделения.
4. Зафиксируйте код `FS-403` и время отказа.

IT не предоставляет доступ только на основании скриншота ошибки. Требуется заявка с владельцем данных, ролью пользователя и деловой причиной.

## Предоставление доступа

Постоянный доступ сотрудника согласует владелец папки. Для подрядчика дополнительно указываются организация-партнёр, ответственный сотрудник «ВекторЛаб» и дата окончания. Максимальный срок одного разрешения подрядчику — 90 дней; продление оформляется новой заявкой до истечения срока.

Подрядчика нельзя включать в общую группу подразделения, если ему нужен только один проектный каталог. Выдаётся минимальное разрешение на конкретную папку. Исключение допускается для утверждённой проектной роли, заранее описанной владельцем данных и службой безопасности.

Удаление сотрудника из проекта прекращает доступ, но не удаляет созданные им файлы. Передавать пароль или подключать папку под чужой учётной записью запрещено.

## Синхронизация OneDrive

Значок паузы означает, что синхронизация остановлена пользователем; её можно возобновить из меню клиента. Красный крест требует открыть список проблем и проверить имя файла, свободное место и доступ. Файлы с неподдерживаемыми символами следует переименовать, сохранив смысл названия.

Если пользователь случайно изменил или удалил файл, сначала нужно прекратить дальнейшее редактирование и воспользоваться историей версий либо корзиной OneDrive. Сроки хранения и порядок восстановления описаны в `VL-IT-011`.

## Ссылки на документы

Ссылка «Только сотрудники ВекторЛаб» не подходит внешнему подрядчику. Для внешнего получателя создаётся адресная ссылка после одобрения владельца данных и только на требуемый срок. Публичные ссылки без проверки личности запрещены.

Права по ссылке не заменяют правила доступа к исходной сетевой папке. Если документ скопирован из сетевой папки в OneDrive для совместной работы, владелец обязан убедиться, что копирование разрешено классификацией данных.
